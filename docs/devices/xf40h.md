# XF40H 首个目标设备

用户指定设备为 XF40H，系统为 ArkOS。这里记录设计目标；尚未接触真机或读取设备系统信息。

## 设备基线

| 项目 | 当前依据 |
| --- | --- |
| 设备 | XF40H，用户确认 |
| 系统 | ArkOS，用户确认；具体版本与分支待实测 |
| SoC | RK3326，固件项目资料将 XF40H 归入这一设备家族 |
| 屏幕目标 | 720×720、1:1，后续读取实际显示模式确认 |
| 编译目标 | Linux aarch64，后续确认用户空间和依赖版本 |
| 运行入口 | PortMaster / Ports |

ArkOS4Clone 是面向这类设备的固件移植项目。不能据此认定用户安装的是某个特定版本，
也不能把其他 ArkOS 设备上的成功测试代替 XF40H 验证。

## 方屏显示方案

优先保持完整地图与文字，以最近邻缩放呈现像素素材，上下留边。
提供整数缩放与等比最大化两种设置，默认整数缩放。

对于已有一代掌机实现的 320×240 逻辑画布：

- 整数 2 倍：640×480，置于 720×720 居中；左右各 40 像素、上下各 120 像素留边。
- 等比最大化：720×540，置于屏幕居中；上下各 90 像素留边，使用最近邻采样。

两代已使用同一 320×240 逻辑画布完成上述布局，生成方屏运行截图并检查。
已在 ARM64 容器软件渲染后端验证；XF40H 的实际显示后端和控制器仍待真机确认。
首次移植不利用边缘空白显示新的能力提示，以免透露原作尚未解锁的机制。

## 真机阶段需要记录

- 实际固件名称、版本，`uname -m` 与系统依赖版本。
- PortMaster 版本、控制目录和实际 ROM 根目录。
- SDL2 显示后端、720×720 模式及控制器映射是否可用。
- 正常保存退出、重新进入、撤销和两代存档隔离的结果。

这些信息用于选择兼容工具链和启动环境，不要求玩家在最终安装包中手动配置。
